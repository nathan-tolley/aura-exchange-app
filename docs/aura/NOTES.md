# Notes

Decisions made while building that `DESIGN.md`, the references and `DECISIONS.md` don't spell out. Newest last. If one of these turns out to matter for the game or the contract, it moves to `DECISIONS.md`.

- **2026-10-24 · iPhone is portrait only.** Every drawn screen is 390×844 portrait, and nothing in the plan needs landscape. `Info.plist` keeps the iPad list as the template had it.
- **2026-10-24 · `aura://` deep links.** `Info.plist` registers the `aura` scheme and sets `FlutterDeepLinkingEnabled`, so go_router receives `aura://invite/CODE` as the route `/invite/CODE`.
- **2026-10-24 · No icon fonts.** `cupertino_icons` is removed and `uses-material-design` is false. Every glyph is an `AuraIcon` painted from `design/icons.json`.
- **2026-10-24 · `API_BASE_URL` can be empty.** The release workflow always passes `--dart-define=API_BASE_URL=` from the repo variable, so an unset variable arrives as `''`. In A2, `client.dart` must treat `''` as "not set" and fall back to a default, rather than building URLs on an empty base.
- **2026-10-24 · Previewing from a Claude session.** The debug web build (`flutter run -d web-server`) stalled while loading its modules in Claude's hidden browser pane. A release build served statically renders fine: `flutter build web --release --dart-define=API_BASE_URL=http://localhost:4010`, then serve `build/web`. Nathan's own `flutter run -d chrome` is unaffected.
- **2026-10-24 · Prism mocks every error the same way.** All error responses share one schema with no examples, so forced codes all return the same `INSUFFICIENT_CASH` body. Logged as `CONTRACT-REQUESTS.md` #1; error tests use local fixtures until it's fixed.
- **2026-10-24 · Fonts are the variable files from google/fonts.** Flutter 3.47 maps `FontWeight` onto the `wght` axis by itself, so no `fontVariations` are needed. Optical size stays at each font's default: a probe matched the reference `Money.png` at default opsz (ink 528×89 px against 531×89), while browser-style opsz = font size didn't (523×85). Inter ships inside the iOS app too (about 0.9 MB), since pubspec fonts can't be limited to one platform.
- **2026-10-24 · One base text style.** `auraBaseTextStyle()` (the `body` style, Inter off iOS, with the tracking and leading below) is the app's default text style, so `AuraType` styles inherit the right sans and Cupertino's default tracking never leaks in.
- **2026-10-24 · Matching the web references' text.** The base style carries their −0.005em tracking (−0.075) and CSS-style even leading. Control labels (buttons, tabs, segments, nav rows, link and banner/toast actions) use `auraControlText()`: no tracking and proportional figures, as Chrome's `<button>` does, which also keeps Inter's tabular hyphen from spacing out "Super-injunction". The serif is Newsreader at optical size 16, the cut the references used (its line widths matched to 0.2%); that's `opticalSize` on the Analyst group in `design/tokens.json`.
- **2026-10-24 · Hairlines take no space.** The references draw them as inset box shadows, so they're `foregroundDecoration`s here; a `Container` border would add 1 pt per row.
- **2026-10-24 · A reference-renderer quirk to recheck in A3.** Text at 12.5 pt (chips, tags, nav subtitles, stat labels) sits 2 pt higher in the references than CSS metrics predict, while 12 and 13 pt text matches. It isn't copied here; check it against W01–W13 before deciding. *2026-10-25: decided, it's copied.* W09's row subtitles and W12's nav subtitles sit exactly 2 pt higher than the goldens did, while the 15 pt titles beside them match, so the references are consistent about it. `auraLiftFootnote()` (`lib/design/text.dart`) moves the ink of 12.5 pt text up 2 pt without changing layout, in the tag, status chip, nav row, quote card, stat card, stepper, stock row and action label. Every one of those components moved closer to its reference (Tag 0.48 → 0.04%, StatusChip 2.73 → 0.50%, StatCard 1.04 → 0.27%, StockRow 1.84 → 1.21%).
- **2026-10-24 · Generated files aren't formatted.** Never run `dart format` over `lib/design/tokens.dart` or `icon_paths.dart`; the drift test compares them with the generator's exact output.
- **2026-10-24 · Goldens are 2×.** `matchesGoldenFile` captures a `RepaintBoundary` at 1×, so golden tests capture from the root view instead (no boundary above the subject), which gives physical pixels at the test's device pixel ratio.
- **2026-10-24 · Dev servers outlive their shell.** Stopping a background `flutter run` or `npx prism` shell leaves `dartvm.exe` or `node.exe` holding the port (5555, 4010). Stop the owning process (`Get-NetTCPConnection -LocalPort 5555`).
- **2026-10-24 · The debug web build stalls in a hidden browser pane.** It stops at "DDC is about to load"; use the release web build to look from a Claude session. In Nathan's Chrome, `flutter run -d chrome` is fine. The State Gallery is debug-only, so open it there at `/#/gallery`.
- **2026-10-25 · The generated client needs two naming fixes.** swagger_parser 1.45 de-duplicates class names case-sensitively, so a component and an inline schema named after a property can generate as one class, the second overwriting the first. It hit `Side` (the trade side was replaced by `ListingSummary.myPosition`'s LONG/SHORT, so quotes would have decoded `BUY` as unknown) and `Error` (the envelope was replaced by its inner object). `swagger_parser.yaml` steers the inline `side` to `PositionSide` and renames `Error` to `ErrorDetail`; `test/api/generated_test.dart` guards `Side`. The app parses error bodies itself (`lib/api/errors.dart`), so the lost envelope class doesn't matter. The generated code is committed, because the iOS workflow doesn't run generators.
- **2026-10-25 · How far a time stays short.** The contract says relative time under an hour, then exchange-local time; the references show `as of 9:41 pm`, `Closed until 7:00 am` and `Invited 2 h ago`. So `formatMoment` shows the time alone within 12 hours either way, then `Tue 7:00 am` within 6 days, then `5 Nov, 7:00 am` (day before month, since the group uses A$). `formatAgo` is for "how long since" rows like W12's, which stay relative past an hour.
- **2026-10-25 · Error copy follows the drawn screens, and drops what it can't know.** `errorCopy()` gives a title, body, action and reference; the screen decides banner, sheet, toast or full screen. Where a param is missing or malformed, that clause is dropped ("You don't have enough cash" instead of "You're A$null short"). Copy never states a game rule the server owns (the 10% order cap, the 30 s unsend window, the stimulus schedule); it uses the params instead, and asks for one more (contract request #2). The requote banner (W06) and the Chapter 7 banner (W04) have no button, as drawn: their sheets are the fix.
- **2026-10-25 · W13 promises a notification the app can't send.** Its footnote says "You'll get a notification when it's back", but there's no push yet and the in-app inbox can't reach a closed app. The copy keeps the drawn title and body, and the reference (`503 · 7F2K`); the footnote's lead-in is a question for Nathan before A3's golden.
- **2026-10-25 · Prism now mocks each error code.** Since draft.6 every shared error response has one named example per code. Force one with `Prefer: code=409, example=QUOTE_STALE`; without `example=` Prism serves the first (`E409` → `QUOTE_STALE`, `E422` → `INSUFFICIENT_CASH`). - **2026-10-25 · Only a connection error is "offline".** dio reports an unreachable server or a dropped connection as `connectionError` on iOS and on the web, and that alone becomes `APP_OFFLINE` (W11).
